SimpleSpa Code Review - Current Status Report
📊 Project Overview
SimpleSpa is a comprehensive multi-tenant spa/salon management system built with:

Frontend: React + TypeScript + Vite + Wouter (routing) + TanStack Query
Backend: Node.js + Express + TypeScript
Database: PostgreSQL with Drizzle ORM
Auth: Replit Auth + Passport (local strategy for super admin)
Codebase Size: 113 client files, 28 server files (141 total TypeScript files)

2. UAE VAT (FTA) Compliance Issues 🇦🇪
Status: 60% compliant - Missing critical fields

Critical Gaps:

❌ Missing TRN (Tax Registration Number) fields:
spas.taxRegistrationNumber - Business TRN
invoices.supplierTrn - Spa's TRN on invoice
invoices.customerTrn - Customer's TRN (B2B)
invoices.invoiceType - Full vs Simplified
❌ No "TAX INVOICE" designation on invoices
❌ Using tax-inclusive pricing (should be tax-exclusive per FTA)
❌ No 5-year data retention policy enforcement
⚠️ No Input VAT tracking for expenses
⚠️ No VAT return report generation
Impact: Cannot issue legally compliant invoices in UAE

Note: The system already has taxRegistrationNumber fields in schema according to line 86-87 of shared/schema.ts, but may need additional invoice-related fields.

5. Pricing Model Inconsistency
Status: System uses tax-inclusive pricing, but FTA recommends tax-exclusive

Current:

Service prices stored as inclusive (e.g., AED 105 includes VAT)
Backend calculates backwards: net = price / 1.05
Recommended:

Store base prices (e.g., AED 100)
Add VAT: total = base * 1.05
Impact: Audit complications, non-standard UAE practice
