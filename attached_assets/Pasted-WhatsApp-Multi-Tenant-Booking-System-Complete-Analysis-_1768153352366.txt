🚨 CRITICAL ISSUE: Multi-Tenancy Gap
The Problem
Your WhatsApp service currently uses a SINGLE Twilio client initialized at service level:

// server/whatsappBookingService.ts:48
private twilioClient: any = null;
private twilioFromNumber: string = '';

async initialize(accountSid: string, authToken: string, fromNumber: string) {
  this.twilioClient = twilio(accountSid, authToken);
  this.twilioFromNumber = fromNumber;
}

Why This Breaks Multi-Tenancy:

When customer sends "Hi" to Spa A's WhatsApp (+971501234567)
Webhook receives: To: whatsapp:+971501234567
Current code ignores To field ❌
Uses global Twilio client (wrong credentials!)
Reply comes from wrong spa's number ❌
What Should Happen:
// Incoming message
{
  From: "whatsapp:+971509999999",  // Customer
  To: "whatsapp:+971501234567",    // Spa A's WhatsApp number
  Body: "Hi"
}

// System should:
1. Extract To: +971501234567
2. Query: SELECT * FROM spa_notification_credentials 
          WHERE from_phone = '+971501234567' AND channel = 'whatsapp'
3. Load Spa A's credentials (accountSid, authToken)
4. Initialize Twilio client with Spa A's credentials
5. Auto-set conversation context: spaId = Spa A
6. Reply using Spa A's WhatsApp number
