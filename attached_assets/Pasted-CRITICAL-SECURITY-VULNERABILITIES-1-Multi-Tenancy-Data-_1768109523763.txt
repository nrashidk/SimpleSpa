CRITICAL SECURITY VULNERABILITIES
1. Multi-Tenancy Data Leakage (SEVERITY: CRITICAL)
Impact: Admins from one spa can view and modify data belonging to other spas.

Affected Endpoints:

/api/admin/service-categories - Returns ALL categories across ALL spas
/api/admin/services - Returns ALL services
/api/admin/memberships - Returns ALL memberships
/api/admin/customers - Returns ALL customers (privacy violation)
/api/admin/staff - Returns ALL staff members
/api/admin/products - Returns ALL products
/api/admin/promo-codes - Partially filtered
/api/admin/bookings - Partially filtered by staff role, not spa
/api/admin/loyalty-cards - Returns ALL loyalty cards
/api/admin/product-sales - Returns ALL sales
/api/admin/vendors - Returns ALL vendors
/api/admin/expenses - Returns ALL expenses
/api/admin/bills - Returns ALL bills
/api/admin/transactions - Returns ALL transactions
Root Cause:

Database schema missing spaId foreign key on: products, vendors, expenses, bills, transactions
API endpoints use storage.getAllX() without filtering by req.adminSpa.id
Example (routes.ts:2104-2112):

app.get("/api/admin/services", isAdmin, async (req, res) => {
  const services = await storage.getAllServices(); // NO SPA FILTERING!
  res.json(services);
});

Remediation:

Immediate: Add spaId filtering to ALL admin GET endpoints
Schema migration: Add spaId to products, vendors, expenses, bills tables
Validation: Add ownership checks on UPDATE/DELETE operations
Testing: Write integration tests for tenant isolation
2. Unauthenticated File Upload (SEVERITY: CRITICAL)
Location: routes.ts:157-170

app.post('/api/upload/license', upload.single('file'), (req, res) => {
  // NO AUTHENTICATION CHECK!
  if (!req.file) {
    return res.status(400).json({ message: 'No file uploaded' });
  }
  const fileUrl = `/uploads/licenses/${req.file.filename}`;
  res.json({ fileUrl });
});

Impact:

Anyone can upload files to the server
Potential for storage exhaustion (DoS)
Malicious file uploads
No virus scanning
Remediation:

Add isAuthenticated middleware
Implement virus scanning (ClamAV)
Add rate limiting (max 3 uploads/hour)
Move to cloud storage (S3) with signed URLs

5. Missing Security Headers & Rate Limiting (SEVERITY: HIGH)
Missing:

CORS configuration (no cors middleware found)
Helmet (no security headers: CSP, HSTS, X-Frame-Options)
Rate limiting (public booking endpoint vulnerable to spam)
Impact:

XSS via missing CSP
Clickjacking via missing X-Frame-Options
Booking spam/DoS attacks
API enumeration
Remediation (server/index.ts):

import helmet from 'helmet';
import cors from 'cors';
import rateLimit from 'express-rate-limit';

app.use(helmet());
app.use(cors({ origin: process.env.ALLOWED_ORIGINS }));

const limiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 100
});
app.use('/api/', limiter);

const bookingLimiter = rateLimit({
  windowMs: 60 * 60 * 1000,
  max: 10
});
app.use('/api/bookings', bookingLimiter);
